# Architecture

## Overview
A classic three-tier web app:

```
React (Vite, Tailwind) ──HTTP/JSON──> FastAPI ──Motor (async)──> MongoDB
```

## Backend layout
- `app/main.py` — FastAPI app, CORS, router wiring, startup index creation.
- `app/database.py` — Motor client + collection handles + index creation.
- `app/config.py` — environment-driven settings (pydantic-settings).
- `app/dependencies.py` — JWT auth dependency + role-based guards.
- `app/schemas/` — Pydantic request/response models and shared enums.
- `app/routes/` — one module per resource (auth, requests, comments, ...).
- `app/services/` — business logic, kept out of route handlers:
  - `impact_engine.py` — rule-based impact/priority scoring.
  - `sla_service.py` — SLA deadline math and status evaluation.
  - `recurring_detector.py` — MongoDB aggregation for recurring issues.
  - `routing_service.py` — rule-based department/staff routing suggestion.
  - `audit_service.py`, `notification_service.py` — logging/notification writes.
- `app/utils/` — password hashing/JWT, atomic request-number generator.
- `app/seed/seed_data.py` — demo data generator for Nexus Institute of Technology.

## Frontend layout
- `src/context/AuthContext.jsx` — JWT session state, login/logout.
- `src/services/api.js` — single axios instance + typed endpoint helpers.
- `src/components/` — Sidebar, Topbar, status pills, route guard.
- `src/layouts/AppLayout.jsx` — shared authenticated shell.
- `src/pages/{public,student,staff,lead,admin,shared}/` — route-level pages.

## Data model
See `README.md` → "Core Entities" for the full field list. Every service
request has a human-readable `request_number` (CSR-YYYY-00001) generated by
an atomic MongoDB counter (`app/utils/request_number.py`), separate from its
internal ObjectId.

## Why no AI/ML
Every "smart" feature (impact scoring, SLA clocks, recurring detection,
routing suggestions) is implemented as fixed rule tables, MongoDB
aggregation pipelines, and timestamp arithmetic — fully deterministic and
explainable, with no machine learning models or third-party AI APIs
involved anywhere in the request lifecycle.
